Setup steps

  1. Deploy the Ai BLINE web app (e.g. Vercel).
  2. Rebuild this APK with your URL via the
    Android APK GitHub Action.
  3. Install the new APK and open it.

Server URL is set at build time via AIBLINE_SERVER_URL in capacitor.config.ts.
